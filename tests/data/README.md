# Public reference regression fixture

`NC_007933.1.gb` is the NCBI RefSeq record for *Orbinia latreillii* mitochondrion,
complete genome (15,558 bp), retrieved 2026-11-12 from:

https://eutils.ncbi.nlm.nih.gov/entrez/eutils/efetch.fcgi?db=nuccore&id=NC_007933.1&rettype=gbwithparts&retmode=text

The unchanged record exercises before-position COX1/COX3 boundaries and
rRNAs named via product qualifiers (`s-rRNA`, `l-rRNA`) without gene qualifiers.
It is a parser regression fixture, not a general reference database.
